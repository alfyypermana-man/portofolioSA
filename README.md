# Portofolio — Axon Learning Case Study

## Buka di VS Code
1. Ekstrak ZIP ini.
2. Di VS Code pilih File → Open Folder, lalu pilih folder portofolioupdate-main.
3. Buka projects.html atau case-study.html menggunakan browser. Bisa juga menggunakan ekstensi Live Server jika sudah tersedia, lalu klik Go Live.
4. Dari Projects, klik View case study pada kartu Axon Learning.

Tidak memerlukan npm, Node.js, database, atau proses build.

## File yang ditambahkan
- case-study.html: intro, proses desain, prototipe, rencana pengujian, kesimpulan.
- case-study.css: tampilan responsif halaman proyek.
- axon-prototype.js: filter katalog, detail kelas, formulir, tinjau data, dan konfirmasi simulasi.

## File yang diperbarui
- projects.html: kartu Axon Learning dan perbaikan tag kosong pada kartu lama.
- style.css: gaya kartu pratinjau Axon.

## Sesuaikan sebelum dipublikasikan
- Edit nama proyek, cakupan, dan penjelasan di case-study.html.
- Edit array courses di axon-prototype.js untuk mengganti data ilustrasi.
- Tambahkan durasi dan peran yang benar-benar dilakukan.
- Riset, metrik hasil, persona tervalidasi, dan pengujian belum dilakukan. Jangan menyajikan asumsi sebagai hasil riset.
- Prototipe hanya berjalan di browser; tidak ada pendaftaran atau transaksi nyata.
- Proyek Magangku dan tautan Figma lama tetap tersedia. Font Google dan QR lama memerlukan internet; fitur baru tidak bergantung pada layanan eksternal.

## Pemeriksaan manual
- Projects → Axon → case study → Coba prototipe.
- Cari anatomi; pilih format Offline; periksa keadaan tanpa hasil.
- Pilih kelas, isi data contoh, kembali mengedit, lalu konfirmasi.
- Coba nama kosong/email tidak valid dan tombol Mulai ulang.
- Periksa tampilan ponsel dan navigasi keyboard.
